# 手册驱动的嘉立创EDA电路与PCB设计

把参考板经验转化为当前需求下可追溯的设计决定。先读确切型号和封装的手册、硬件应用笔记及典型应用，再对照实际工程，最后绘制或评审。参考板的画法、参数和分地方式都有适用条件。

## 确定工作对象和工具

- 识别本次是只读学习、设计、修订还是归档。学习任务保持只读；用户要求修改时，在其范围内执行。
- 优先使用可用的嘉立创EDA结构化连接器、MCP或本地CLI，先检查连接健康状态，回读窗口、工程及文档身份。打开的标签或页面标题不能代替连接确认。
- 根据当前工具公开的schema、help或动作目录选择读写方法。历史动作名只作检索线索，不假设所有版本都支持。
- 写入时显式指定当前工程和文档，防止落到其他窗口或页面。缺少连接器时可以准备离线方案，但应标记“未应用到工程”。
- 优先读取器件、引脚、网络和几何数据。截图或官方导出图用于补充图面可读性及结构化数据缺失的信息，避免连续截图代替网络核对。

## 从手册形成电路决定

为每个待绘制或深入审查的模块建立一条记录：

`完整型号/封装 → 手册版本与章节/图号 → 应用条件 → 引脚连接 → 参数计算 → 参考工程差异 → 当前实现 → PCB约束 → 验证结果`

1. 核对器件完整料号、封装、引脚表及实际库器件，避免用功能框标题代替器件身份。检查具体系列的电源、地、参考、复位、时钟、启动配置和模式脚。
2. 查阅原厂数据手册、硬件应用笔记、典型应用及相关勘误。寄存器手册用于补充外设模式、触发和时序，不能替代外围电路依据。
3. 分清绝对最大额定值、推荐工作条件、典型值和参考设计测试条件。电压、温度、封装及工作模式不一致时重新论证。
4. 解释关键外围元件的作用并计算取值。计算中标明输入条件、单位、容差和理想化假设；不要把数学边界写成实际额定能力。
5. 对照参考工程的真实网络、BOM及相关固件参数。发现分流阻值、增益、ADC参考或器件版本冲突时列出差异，避免只采信图面或介绍文字。
6. 型号、模式或关键依据未明确的模块保持待定，继续完成已明确部分。已有本地手册和笔记应先复用并核对版本；需要新资料时查原厂来源，记录版本和适用章节。

## 原理图表达与连接

- 按供电、控制、驱动、功率、采样及接口等实际功能分区，保持信号流向和重复单元一致。重复桥臂适合横向对照，外围与本地电路放在一起。
- 使用真实器件和引脚。多脚MOS的重复源漏脚需逐脚核对，不为简化图面把八脚器件换成三脚器件。
- 页内普通连接优先使用清楚的网络标签；跨页接口按信号语义和工具的层级规则使用端口。标签和端口必须实际接到导线或引脚。
- 端口旋转值不是方向证据。结合符号接点、引脚坐标及导出图检查出线和文字方向；给位号、参数、网络名和图框留出空间。
- 保留DNP、N/A、焊桥及装配条件。版面拥挤时按用户选择拆页或调整分区，保持可读间距。
- 在返回这些字段的接口中，原理图修改句柄通常是 `primitiveId`；`uniqueId` 用于原理图与PCB关联。以当前schema为准，避免混用。
- 多单元器件的导出若报重复，先查器件表和原生网表，确认是否为同一实体的多个单元，再判断是否需要修复。
- 审查封装时核对手册和焊盘映射；是否允许修改封装由本次授权和现有受控流程决定，不因排版任务而顺带替换。

## PCB按电流回路推导

对重要连接说明：电流从哪里出发、经过哪里、从哪里返回，哪些节点敏感，几何数据能证明什么。作者未说明的布局目的写成工程推断。深入检查对应模块时，按需读取 [PCB与采样检查要点](references/pcb-review.md)。

- 先确定机械接口、功率与控制区、层叠及参考层，再围绕关键回路布局。参考板的相对位置可以借鉴，电压、电流、热与制造能力需按当前条件决定。
- 栅极、自举、换流、去耦和采样分别检查往返回路；“距离近”“铜面积大”“过孔多”均不足以证明效果。
- 铺铜先查所属网络、实际填充和连通性，再解释用途。内层可能有多个网络；有铜对象不等于连续地平面。
- 分析裂缝、铜岛、铜颈和跨层返回路径。AGND/PGND/GND命名不能代替回流分析，也不强制把地平面分割。
- 用真实板框和单位检查尺寸及孔位。工具返回AABB或投影时仅作估计；二维投影交叉不等于跨层电气相连。

## 修改、保存与确认

1. 修改前记录目标身份与相关连接、参数、几何基线；大范围修改按模块分批并保留可恢复状态。
2. 优先使用结构化操作。若确需底层源修改，先确认格式、修改范围和恢复方式；不要把离线生成文件直接当作已经落到工程的结果。
3. 请求超时或出现服务端错误时，先回读确认是否部分生效，再决定是否重试，避免重复创建。
4. 完成修改后显式保存，重载目标文档，再重新回读。重新核对器件身份、引脚网络、NC、页面归属及原理图与PCB关联。
5. 连接核对与图面检查分别进行：使用网表/结构化读数核对电气连接，使用当前官方导出图检查重叠、图框、端口和文字。
6. 对修改范围执行适用的原生ERC/DRC及几何检查，保留实际返回结果。接口只返回布尔值时不要声称已取得详细错误清单。检查不可用时明确保留为待验证。

## 交付与证据边界

用简洁中文解释决定，分清手册要求、工程回读事实、几何观察、计算假设、工程推断及待验证项。

- 电路交付说明型号、主要接法、参数依据、参考差异及网络核对结果；PCB说明关键回路、取样点、参考层、铜与热的约束及已完成检查。
- 保存成功、回读一致、DRC结果、仿真和实板验证是不同证据，分别报告。未进行的检查明确写出，不能从其中一种推导其余验收。
- 归档时区分本地备份、云端副本和实际导入。文件头、CRC及哈希只证明相应格式或完整性；导入需重新读到工程身份和内容。
- 公开分享仅整理通用方法、脱敏结论及必要的原厂资料链接，不带出个人路径、账号凭据、私有工程UUID、投板文件或未授权再分发的资料。
