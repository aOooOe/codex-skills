# LOL 开黑战绩分析

读取 Windows 国服英雄联盟的本机客户端数据，生成一个可以双击打开的离线报告。自己选择日期和朋友，查看共同胜率、逐人评分、英雄表现、逐场数据与复盘建议。

## 下载后直接使用

1. 下载 **lol-friends-analyzer-windows-x64.zip** 并完整解压。完整包包含 runtime/node.exe；GitHub 自动生成的 Source code.zip 仅为源码。
2. 打开英雄联盟客户端并登录账号，保持客户端运行。
3. 双击 **Start.cmd**。Windows 包自带已核对官方 SHA256 的 Node.js，不需要安装 Python、npm、服务器或申请 API Key。
4. 浏览器打开报告后，在左侧勾选朋友，设置起止日期，点击朋友查看详情和建议。

报告默认写入 Windows 的 Documents/LOL-Friends-Reports。游戏客户端关闭后仍可查看报告；新增对局后再运行 Start.cmd 即可更新，缓存会复用。首次采集可能需要几分钟。可以先双击包内 `demo.html` 查看使用合成数据制作的演示。

如果未找到游戏目录，按住 Shift 右键打开终端，运行：

```powershell
.\Start.cmd -GameRoot 'D:/WeGameApps/英雄联盟'
```

还可以自选输出位置、采集日期：

```powershell
.\scripts\run.ps1 -OutputDirectory 'D:/我的LOL报告' -From '2026-10-01' -To '2026-10-17' -OpenReport
```

日期按北京时间、包含起止日。省略日期时会尽量读取本机日志、客户端索引和现有缓存中的对局，再在页面筛选。多客户端同时运行时可通过 `-ClientProcessId` 选择进程。

## 作为 AI Skill 安装

下载完整包后双击 `Install-Skill.cmd`，把完整技能（含运行时）复制到当前用户的 `.agents/skills/lol-friends-analyzer`。在能够执行本地命令的 Windows Codex 中说：

> 使用 $lol-friends-analyzer 分析我和朋友最近的战绩，生成本地报告。

首次未出现时刷新或重启 AI 客户端。源码版也可以安装，但需要 PATH 或宿主提供 Node.js 20 以上的运行时；完整 Windows 包无需另装。

## 页面能看什么

- 开黑总览：按朋友共同对局的并集去重，显示场数、胜率、评分与趋势。
- 朋友档案：英雄、英雄定位、评分五维拆解、胜负表现和你在完全相同对局的表现。
- 个人建议：观察数据、待复查问题、下一步行动和对应对局，随筛选更新。
- 逐场数据：双方玩家、装备、海克斯强化、关键数据与评分依据。
- 导出：下载携带当前朋友选择和筛选的完整报告。**导出包含全部已采集记录，接收者可以修改筛选。**

报告的脚本、样式和数据全部内嵌；查看报告无需网络，也不会把战绩上传到网站。不能使用本地存储时，导出仍能保留选择。

## 数据与分数的含义

支持召唤师峡谷、普通大乱斗、海克斯大乱斗，三个模式独立评分。竞技场等模式保留采集信息但不进入本版评分。朋友只包含与你同队的场次，不代表他们独自游戏时的总体水平；玩家由你手动选择，同队出现不能证明预组队。

分数是**本工具表现分**，并非 Riot、WeGame 或世界赛官方个人评分。使用同模式、同英雄主定位的本机样本作参照，公开权重，逐局计算后等权平均。至少十场可评分记录才进入稳定排名。坦克开团、辅助保护、控制质量、决策等不能由这些统计完整衡量。详见 [评分说明](references/scoring.md)。

采集范围受客户端和本机日志限制，不保证账号完整历史。历史接口重复返回最近 20 场时，工具会读取本地日志中的对局 ID 补查，并明确失败数量。接口返回缺失字段时不生成虚假零分。

验证状态：已用 366 场真实本地记录验证（354 场海克斯、12 场竞技场隔离），并通过离线页面交互验证。Windows PowerShell 5.1 在线端到端实测通过，包括自动发现游戏目录、真实客户端读取、重复页检测、日志补查和缓存复用；本次枚举 368 个候选 ID，其中一个旧对局返回 404，报告明确保留失败状态。峡谷和普通大乱斗已通过结构样例测试，尚待真实客户端样本验证。

## 开发与打包

```powershell
node --test tests/core.test.mjs
.\scripts\package.ps1 -NodeBinary 'C:/node/node.exe' -OutputDirectory 'D:/dist'
```

浏览器验收脚本需要开发环境安装 Playwright 与 Edge，不属于使用时依赖。包内 `tests/fixtures.mjs` 只有合成数据，不包含私人战绩。

Node.js 24.19.0 运行时按官方校验值验证并附带 [完整许可证](assets/NODE-LICENSE.txt)。项目与 Riot Games 无隶属或背书关系。
